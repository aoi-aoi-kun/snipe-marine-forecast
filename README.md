# 七里ヶ浜沖の予報

相模湾、北緯 35.25°・東経 139.50° の天気、気温、風向、風速を、96時間先まで表示します。48時間先までは日本時間の6時間ごと、その先は12時間ごとです。地点は NOAA GFS の 0.25° 格子で、七里ヶ浜の海岸を含む升です。

数値は NOAA GFS の毎時値を、その枠の長さにまとめたものです。鎌倉市の警報・注意報は、気象庁ホームページの公開データです。申請や API キーは使いません。

## 起動

```bash
npm install
npm run dev
```

ブラウザで http://127.0.0.1:3847 を開きます。最初の表示では、NOMADS から約100個の小さな GRIB2 を取るため、1分ほどかかることがあります。同じ初期値のあいだはサーバが結果を保存します。

```bash
npm test
npm run lint
```

## 画面の見方

- 各枠の天気は、降水量が 1mm 以上なら雨、それ未満で平均雲量が 80% 以上なら曇り、それ以外は晴れです。
- 風の図は平均風速で、うすい部分は最大までです。棒の幅はその枠の長さです。方位の矢印は風の向かう向き、言葉は吹いてくる向きです。
- 風向は東西・南北の成分を平均してから、吹いてくる向きに戻しています。風速の最大は、その枠の毎時・地上10m風速の最大です。

出艇の判断は、現場の状況と気象庁の警報・注意報によります。
