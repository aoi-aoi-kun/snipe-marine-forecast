# 七里ヶ浜沖の予報

相模湾、北緯 35.25°・東経 139.50° の天気、気温、風向、風速を、96時間先まで表示します。48時間先までは日本時間の6時間ごと、その先は12時間ごとです。地点は ECMWF IFS の 0.25° 格子で、七里ヶ浜の海岸を含む升です。

数値は ECMWF が公開している IFS（0.25°）の3時間ごとの値を、その枠の長さにまとめたものです。96時間を3時間刻みで覆うため、00 UTC と 12 UTC の初期値を使います。鎌倉市の警報・注意報は、気象庁ホームページの公開データです。申請や API キーは使いません。出典は [ECMWF open data](https://www.ecmwf.int/en/forecasts/datasets/open-data)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）です。

## 起動

Node.js と、eccodes の `grib_ls` が必要です。

```bash
npm install
npm run dev
```

ブラウザで http://127.0.0.1:3847 を開きます。最初の表示では、必要な3時間ごとの全球格子を取ってこの地点の値だけを読むため、数分かかることがあります。同じ初期値のあいだはサーバが格子点の値を保存します。

```bash
npm test
npm run lint
```

## 画面の見方

- 各枠の天気は、降水量が 1mm 以上なら雨、それ未満で平均雲量が 80% 以上なら曇り、それ以外は晴れです。
- 風の図は平均風速で、うすい部分は最大までです。棒の幅はその枠の長さです。方位の矢印は風の向かう向き、言葉は吹いてくる向きです。
- 風向は東西・南北の成分を平均してから、吹いてくる向きに戻しています。風速の最大は、その枠に入る3時間ごとの地上10m風速の最大です。突風ではありません。
- 平均風速が 10 m/s 以上、または最大風速が 13 m/s 以上の枠は出艇不可能です。

それ以外の出艇の判断は、現場の状況と気象庁の警報・注意報によります。この画面は気象庁の予報ではありません。
